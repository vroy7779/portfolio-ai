# Vaibhav Roy — Portfolio

Production Next.js (App Router) implementation of the portfolio. Built on four approved specification documents: Content Audit, Creative Direction, Design System, and Homepage Blueprint.

## Stack

Next.js (App Router) · React · TypeScript · Tailwind CSS v4 · shadcn/ui (Radix) · Framer Motion · Lenis · React Three Fiber (one Hero moment) · Vercel Analytics

## Running the code

```bash
pnpm install
pnpm dev
```

## Structure

- `app/` — routes, root layout, metadata, global styles
- `components/sections/` — the five homepage sections
- `components/ui/` — shadcn/Radix primitives
- `components/case-study/` — the case-study panel and per-project content
- `components/graphics/` — shared 2D network-graphic background
- `components/three/` — the Hero's 3D scene
- `assets/` — image assets
